# Reference art search: Giant Spider & Harpy/Bat-winged Humanoid

Date: 2026-09-09
Purpose: Find public-domain/CC0 reference art to trace into solid black
silhouettes (mustard-yellow background style), following the same method
used for the wolf and dragon this session (freesvg.org / publicdomainvectors.org /
Wikimedia Commons, fetched with a browser User-Agent, verified visually before
handoff).

## 1. Giant Spider

### Top pick
- **Source page:** https://freesvg.org/spider-vector-clip-art
- **Download URL:** https://freesvg.org/download/1291 (button requires an
  active session cookie from visiting the page first — a bare `curl` with no
  cookie/referer returns an empty response; a normal browser visit works fine.
  Direct raster fallback: https://freesvg.org/img/1311386118.png)
- **License:** CC0 / Public Domain (page's schema.org metadata:
  `https://creativecommons.org/publicdomain/zero/1.0/`; attributed to OpenClipart)
- **Pose/readability:** Clean side-view spider (like a tarantula/wolf spider),
  legs splayed to front and back so all legs read as distinct, fangs and
  cephalothorax/abdomen clearly separated. Currently colored (grey/black/tan),
  not a flat silhouette, but the outline is simple and well-suited to tracing
  into solid black. Best match for "side view, legs distinct, reads
  creepy/threatening" of everything found.

### Backup candidates
- https://freesvg.org/silhouette-of-a-spider (download 188048, direct image
  https://freesvg.org/img/1589971621spider-stencil-silhouette-freesvg.org.png) —
  already a solid black stencil-style silhouette with segmented/jointed legs
  and visible eyes/fangs — good creepy read, but it's a front-facing view, not
  side/3-4.
- https://freesvg.org/spider-silhouette (download 66523, direct image
  https://freesvg.org/img/Spider-Silhouette.png) — already solid black, very
  clean and symmetric, all 8 legs clearly separated — but it's a top-down view,
  not side/3-4.
- Rejected: https://freesvg.org/cartoon-spider-silhouette ("Little Miss Muffet
  Spider") — top-down, cartoonish googly eyes, reads cute rather than
  threatening.
- publicdomainvectors.org's spider silhouette listing page is dominated by
  embedded Adobe Stock ad thumbnails (not their own CC0 art) and returned a
  403 to a plain WebFetch; not worth pursuing further given the freesvg.org
  options already found.

## 2. Harpy / Bat-winged humanoid

True side-view "flying through the air" public-domain art of this subject is
scarce; the classic public-domain motif is the **heraldic harpy** — a woman-
headed bird-of-prey shown front-on with both wings fully spread ("wings
displayed") and taloned legs. That reads clearly as an aerial monster and,
being fully symmetric, is very easy to trace/mirror/scale like the dragon.

### Top pick
- **Source page:** https://commons.wikimedia.org/wiki/File:Coa_Illustration_Elements_Harpy_Rising_Wings_Displayed.svg
- **Direct SVG:** https://upload.wikimedia.org/wikipedia/commons/0/03/Coa_Illustration_Elements_Harpy_Rising_Wings_Displayed.svg
- **License:** Public Domain (Public Domain Mark 1.0; US public domain as
  published before 1931 — classic heraldic clip-art style)
- **Pose/readability:** Both wings fully spread symmetrically ("wings
  displayed, rising"), nude female torso/head with flowing hair, clawed bird
  legs/talons clearly visible at the bottom. Vector SVG line art (not a flat
  silhouette — has internal feather/hair line detail — but a clean, closed
  outline good for tracing). Pose is more "standing/rising with wings spread"
  than a banked mid-air side view, but the full wing spread reads clearly as
  an aerial creature and mirrors/scales the same way the dragon did.

### Backup candidates
- https://commons.wikimedia.org/wiki/File:Harpy.PNG
  (direct: https://upload.wikimedia.org/wikipedia/commons/5/56/Harpy.PNG) —
  same heraldic motif, by John Vinycomb, 1906, PD-old-70, Public Domain Mark
  1.0. Smaller/rougher than the SVG version above and functionally
  redundant with it (this SVG is a cleaner vector redraw of essentially the
  same classic pose).
- https://openclipart.org/detail/310907/gargoyle-by-ladyofhats
  (download: https://openclipart.org/download/310907, PNG preview:
  https://openclipart.org/image/2000px/310907) — OpenClipart, 100% public
  domain. A crouching/perched bat-winged humanoid gargoyle on architecture,
  clawed feet, horns — genuinely creepy and a true bat-wing (not bird-wing)
  humanoid, but the pose is perched/crouching rather than flying, and the
  illustration includes architectural background clutter (ledge, wall
  moulding) that would need cropping out.
- https://commons.wikimedia.org/wiki/File:A_Harpy._-_Engravings_on_Wood.jpg
  (direct: https://upload.wikimedia.org/wikipedia/commons/3/3c/A_Harpy._-_Engravings_on_Wood.jpg) —
  PD-old-70, 1882 woodcut, genuinely a side view harpy in flight — but it's a
  robed/clothed figure (drapery, not exposed monster form), only one wing is
  visible (side-on relief carving), and the frame also contains an unrelated
  second bearded figure that would need cropping out. Weakest of the three.
